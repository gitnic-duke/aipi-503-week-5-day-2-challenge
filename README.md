# Week 5 Day 2 - Weather report app

Displays a weather app on Streamlit allowing users to select what weather information to view for a city they input

## Instructions for running:
1. Copy your API key from OpenWeather.
If you don't have one, create one after signing up on https://openweathermap.org/
2. Create a .env file with the content OPENWEATHER_API_KEY={your_API_key}
3. Save the file
4. Make sure the required libraries streamlit and matplotlib are installed

Run:
```bash
streamlit run app.py
